# ClipMind AI — 25-Day Roadmap

This is the delivery sequence for a solo Infosys Springboard project with a mentor demo every day. Days 1–7 complete Milestone 1, Days 8–14 Milestone 2, Days 15–20 Milestone 3, and Days 21–25 Milestone 4. A day ends with a demonstrable increment; optional polish never blocks the core flow.

| Day | Mentor-demoable outcome | Milestone |
|---|---|---|
| 1 | Problem, personas, scope, user journeys, repository and issue board | M1 |
| 2 | System architecture, schema, wireframes, API contract | M1 |
| 3 | Next.js and FastAPI shells, Docker Compose, health endpoint | M1 |
| 4 | PostgreSQL, migrations, registration, login, JWT session | M1 |
| 5 | Role-aware app shell and profile settings | M1 |
| 6 | Direct-to-storage video upload, validation and video library | M1 |
| 7 | FFmpeg metadata/audio extraction job and upload-to-job status | M1 |
| 8 | Whisper worker produces timestamped transcript for a short sample | M2 |
| 9 | Transcript viewer, pagination/search, secure download | M2 |
| 10 | Educator transcript editing and version history | M2 |
| 11 | Chunking/preprocessing and short-summary prototype | M2 |
| 12 | Detailed summary, action items and quality/error states | M2 |
| 13 | Persisted summary results and rerun controls | M2 |
| 14 | End-to-end upload → transcript → summary demo and evaluation notes | M2 |
| 15 | Keyword extraction and topic grouping | M3 |
| 16 | Explainable importance scoring from transcript signals | M3 |
| 17 | Timestamped key moments and timeline viewer | M3 |
| 18 | Highlight report/export (Markdown and TXT) | M3 |
| 19 | Per-video content analytics and learner bookmarks/history | M3 |
| 20 | Administrator job/activity dashboard and M3 end-to-end demo | M3 |
| 21 | Unit/integration tests, validation, role/access test matrix | M4 |
| 22 | Performance pass: limits, retry policy, responsive UI, accessibility audit | M4 |
| 23 | Docker production build, environment setup and cloud-ready deployment | M4 |
| 24 | Seed/demo data, mentor presentation, user guide and recovery rehearsal | M4 |
| 25 | Deployed final walkthrough, metrics report and handover | M4 |

Scope rule: v1 accepts uploaded MP4, MOV, WebM and AVI files. YouTube links, live notifications, semantic vector search, automatic scene analysis, Slack/Notion publishing, browser extensions, Kubernetes and multi-cloud failover remain future work unless core milestones finish early.
